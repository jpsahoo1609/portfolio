# JP Sahoo — Interactive AI / ML Portfolio

A ultra-modern, interactive, and dark-themed developer portfolio showcasing end-to-end GenAI systems, RAG architecture, LLM agent automation, and Data Science projects.

Live Portfolio: [jpsahoo1609.github.io/portfolio](https://jpsahoo1609.github.io/portfolio/)

## Featured Projects Showcase

* **Hybrid RAG Research Agent** — High-precision literature search engine combining BM25 keyword matching, vector embeddings, and reranking algorithms (*92% Faithfulness, 83% Answer Relevancy*).
* **GetHiredWithAI** — AI-powered career assistant providing ATS optimization, smart resume parsing, and personalized job matching.
* **AI Agents & Automation** — Autonomous workflows connecting LLM reasoning with external APIs, databases, and structured execution tools.
* **AI Fitness Agent** — Context-aware personal coaching assistant integrating real-world fitness science with algorithmic decision-making.
